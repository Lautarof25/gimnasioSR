# gimnasio

## Planes

Las tarjetas se mantienen directamente en `index.html`, en la sección `#planes`. Cada una incluye un botón para consultar su precio por WhatsApp; no hace falta configurar ni mantener una planilla online.

El CSS crítico del primer pantallazo se mantiene inline en `index.html`; los estilos restantes están en `styles.css` y el comportamiento de la página en `script.js`. El video del inicio se carga de forma diferida y no se descarga si el navegador indica ahorro de datos o movimiento reducido.
